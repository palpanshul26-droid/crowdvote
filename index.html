    How the Pipeline Works

    Four deterministic stages executed in isolated temporary job directories.

    01

    Media Validation & Probe

    Uploads stream in chunks with size enforcement and MIME checks. Authorized URLs pass SSRF validation before ffprobe verifies codec, resolution, frame rate, and duration.

    02

    Gemini Speech Transcription

    FFmpeg extracts compact 16 kHz mono audio, then Google Gemini generates accurate timestamped transcript segments for captions and clip boundaries.

    03

    Gemini Highlight Selection

    Google Gemini analyzes the full timestamped transcript to select self-contained highlights and generate punchy titles, hooks, and descriptions.

    04

    FFmpeg Reframing & Captions

    Each highlight is cropped to 9:16, 1:1, or 16:9, burned with re-timed SRT subtitles, encoded in fast-start H.264/AAC for instant playback, and ready for individual trim or ZIP export.

    Backend Setup & Environment

    Run server.py directly with FastAPI and Uvicorn. All processing happens through real local binaries and configured API keys.

    GEMINI_API_KEY Required in Railway environment variables for Google Gemini transcription & highlights
    GEMINI_MODEL Optional Gemini model override for highlight selection (default: gemini-4-hydrogen)
    ALLOWED_ORIGINS Optional comma-separated Vercel frontend origins for CORS (default: *)
    MAX_UPLOAD_MB Maximum upload file size in megabytes (default: 500)
    1. Install Python dependencies & FFmpeg 
    pip install -r requirements.txt
    2. Configure GEMINI_API_KEY & launch server.py 
    export GEMINI_API_KEY=your_gemini_key && python3 server.py
